# Adopters

No public adopters are listed yet.

This file will recognize verifiable, opt-in use of ETLIR without implying endorsement or exposing
confidential implementation details. A developer or organization may open an **Adoption report**
issue or pull request containing:

- Public name and project or organization link.
- ETLIR version or commit used.
- Source and target adapter names.
- A short description of the use case using non-confidential language.
- At least one public artifact when possible, such as a fork, adapter, integration, issue, or
  technical post.
- Explicit permission to list the submitted information publicly.

Private adoption may be discussed in aggregate only when the adopter supplies written permission
for the exact wording. Maintainers will not manufacture metrics, endorsements, or case studies.

An entry may be removed at the adopter's request or when its public evidence is no longer
available.
