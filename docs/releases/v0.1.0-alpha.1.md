ETLIR's first public alpha establishes a tested vertical slice for platform-neutral
pipeline semantics, translation, and migration evidence.

## What this alpha includes

- Pipeline Semantic Model Specification v0.1 and machine-readable JSON Schemas.
- A synthetic ExampleFlow v1 source adapter.
- A DuckDB SQL target adapter.
- Model validation, structured diagnostics, and fidelity assessment.
- Machine-readable JSON and human-readable Markdown Migration Evidence Bundles.
- A CLI that runs the full source-to-evidence flow.
- Supported and deliberately unsupported end-to-end examples.
- Python 3.11, 3.12, and 3.13 CI coverage.

## Safety property demonstrated

ETLIR does not silently discard behavior. The unsupported external-operation example
retains the source operation, emits a structured diagnostic, blocks target output, and
returns a non-zero CLI status.

## Current limits

This is a pre-alpha reference implementation, not a production-ready migration system.
The supported source and target surface is intentionally narrow. ExampleFlow is synthetic,
DuckDB is the only target adapter, and the project does not claim general semantic
equivalence or independent adoption.

## Try it

```bash
git clone https://github.com/shiva-carimireddy/etlir.git
cd etlir
git checkout v0.1.0-alpha.1
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
pytest
etlir translate \
  --source exampleflow \
  --target duckdb \
  examples/retail-orders/source.exampleflow.json \
  --output build/retail-orders
```

See the repository README and specification for architecture, terminology, and adapter
contracts.
