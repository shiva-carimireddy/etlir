# ADR 0004: Use ExampleFlow to DuckDB for v0.1

- **Status:** Accepted
- **Date:** 2026-09-04

## Context

The first release needs a real end-to-end path without depending on proprietary artifacts,
accounts, cloud services, or employer-specific knowledge.

## Decision

Create ExampleFlow v1 as a clearly synthetic JSON source format. Translate a retail orders
pipeline through Pipeline Semantic Model v0.1 into DuckDB SQL. Execute the successful SQL in an
isolated end-to-end test. Include a second source fixture containing an external HTTP operation
that DuckDB cannot represent.

## Consequences

The first slice is independently reproducible and proves both success and explicit failure paths.
It does not constitute a production source adapter or a claim of broad platform coverage.
